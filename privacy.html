日本語

1. このポリシーの対象

このポリシーは、YouTube チャンネル「ホロアソビ観察日誌【ホロライブ切り抜き】」の運営者（以下「運営者」）が使う投稿・管理ツール kirinuki-upload（以下「本アプリ」）に適用されます。本アプリの利用者は運営者本人だけです。

2. YouTube API サービスの利用

本アプリは YouTube API サービス（YouTube Data API・YouTube Analytics API）を使っています。本アプリを使うことで、利用者は YouTube 利用規約 に同意したものとみなされます。Google による情報の取り扱いは Google プライバシーポリシー をご覧ください。

3. 使う権限と取得する情報

  • 認証のトークン：運営者が Google アカウントでログインしたときに発行されるアクセストークン・リフレッシュトークン。使う権限は次のとおりです。
    • youtube.upload・youtube：運営者のチャンネルへの動画のアップロード、タイトル・説明文・タグ・サムネイルの設定、公開予約、再生リストへの追加
    • youtube.readonly：運営者のチャンネルの動画の一覧と再生数などの統計、運営者の動画に付いたコメント、YouTube の検索結果を読む
    • yt-analytics.readonly：運営者のチャンネルの視聴時間・平均視聴時間・平均視聴率・インプレッションのクリック率・登録者の増減を読む
    • drive.file：公開前の確認用に、本アプリが作った動画とサムネイルを運営者の Google ドライブに置く（本アプリが作ったファイルだけ。運営者のほかのファイルは見えません）
  • 運営者のチャンネルの情報：アップロードした動画の ID・URL・公開日時、再生数・高評価数・コメント数、上の Analytics の数字。
  • 運営者の動画に付いたコメント：字幕や名前のまちがいを指摘するコメントを見つけるために、新しいコメントの本文を読みます。
  • YouTube の検索結果：月に1回、切り抜いている配信者の名前と「切り抜き」で検索し、直近30日の切り抜き動画の数・チャンネルの数・再生数の中央値を数えます。保存するのは数えた結果だけで、ほかの人の動画のタイトルやチャンネル名、ID は保存しません。

視聴者の個人情報（名前・メールアドレス・閲覧履歴など）、チャンネル登録者の一覧は取得しません。

4. 情報の使い方

  • 運営者が編集した動画を運営者自身のチャンネルにアップロードし、公開を予約するため。
  • 運営者のチャンネルの成績（どの動画が見られているか）を運営者が確かめ、動画づくりを改善するため。
  • コメントで指摘された字幕・名前のまちがいを運営者が見つけて直すため。

広告のための利用、第三者への販売・提供はしません。

5. 保存・共有と保存期間

  • トークンは運営者のパソコンの中にだけ保存します。
  • 動画の ID・URL・公開日時と、運営者のチャンネルの数字は、運営者が管理する Google スプレッドシートに記録します（運営者のチャンネルの統計として、運営者の同意のもとで保存します）。
  • 検索結果から数えた数（独自に計算した値）は、同じスプレッドシートに記録します。
  • コメントの本文は、まちがいの指摘かどうかを判定するために、Anthropic 社の AI（Claude）に送ります。指摘と判定したコメントの本文は運営者のパソコンに保存し、30日以内に削除します（指摘の数と内容の要約だけを残します）。指摘でなかったコメントの本文は保存しません。
  • 上のほか、YouTube API から取得した情報は、必要がなくなった時点、遅くとも30日以内に削除または更新します。
  • 本アプリはウェブサイトではないため、Cookie を使いません。

6. 削除と権限の取り消し

本アプリへのアクセス権は、いつでも Google アカウントのセキュリティ設定（サードパーティ アクセス） から取り消せます。取り消した場合、または利用をやめた場合、運営者は保存しているトークンを7日以内に、YouTube API から取得して保存している情報を30日以内に削除します。

English

1. Scope

This policy applies to kirinuki-upload (the "App"), a private upload and management tool used by the owner (the "Owner") of the YouTube channel "ホロアソビ観察日誌【ホロライブ切り抜き】". The Owner is the App's only user.

2. Use of YouTube API Services

The App uses YouTube API Services (YouTube Data API and YouTube Analytics API). By using the App, users agree to be bound by the YouTube Terms of Service. For how Google handles information, see the Google Privacy Policy.

3. Permissions and information we access

  • OAuth tokens issued when the Owner signs in with Google, with these scopes:
    • youtube.upload and youtube: upload videos to the Owner's own channel, set title, description, tags and thumbnail, schedule publication, and add videos to playlists.
    • youtube.readonly: read the list and statistics of the Owner's videos, comments on the Owner's videos, and YouTube search results.
    • yt-analytics.readonly: read watch time, average view duration, average percentage viewed, impressions click-through rate and subscriber changes for the Owner's channel.
    • drive.file: place videos and thumbnails created by the App in the Owner's Google Drive for review before publication (only files created by the App).
  • Data about the Owner's channel: IDs, URLs and publish times of uploaded videos; view, like and comment counts; and the Analytics metrics above.
  • Comments on the Owner's videos: the text of new comments is read to find reports of mistakes (for example, wrong names in subtitles).
  • YouTube search results: once a month, the App searches for the clipped creators' names with "切り抜き" (clip) and counts the clip videos, channels and median views in the last 30 days. Only these counts are stored; titles, channel names and IDs of other users' videos are not stored.

The App does not access viewers' personal information (names, email addresses, watch history) or subscriber lists.

4. How we use information

  • To upload videos edited by the Owner to the Owner's own channel and schedule their publication.
  • To let the Owner review the performance of the Owner's own channel and improve the videos.
  • To help the Owner find and fix mistakes reported in comments.

Information is not used for advertising and is not sold or provided to third parties.

5. Storage, sharing and retention

  • Tokens are stored only on the Owner's computer.
  • Video IDs, URLs and publish times, and the Owner's channel metrics, are recorded in a Google Sheets spreadsheet managed by the Owner (stored as the Owner's own channel statistics, with the Owner's consent).
  • Counts calculated from search results (independently calculated metrics) are recorded in the same spreadsheet.
  • Comment text is sent to Anthropic's AI (Claude) to judge whether it reports a mistake. The text of comments judged to report a mistake is stored on the Owner's computer and deleted within 30 days (only the count and a short summary are kept). The text of other comments is not stored.
  • Any other data obtained from YouTube API Services is deleted or refreshed when no longer needed, and in any case within 30 days.
  • The App is not a website and does not use cookies.

6. Deletion and revoking access

Access can be revoked at any time via the Google security settings page (third-party access). When access is revoked or the App is no longer used, the Owner deletes the stored tokens within 7 days and the data obtained from YouTube API Services within 30 days.
