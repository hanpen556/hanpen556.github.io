日本語

1. このポリシーの対象

このポリシーは、YouTube チャンネル「ホロアソビ観察日誌【ホロライブ切り抜き】」の運営者（以下「運営者」）が使う投稿ツール kirinuki-upload（以下「本アプリ」）に適用されます。本アプリの利用者は運営者本人だけです。

2. YouTube API サービスの利用

本アプリは YouTube API サービスを使っています。本アプリを使うことで、利用者は YouTube 利用規約 に同意したものとみなされます。Google による情報の取り扱いは Google プライバシーポリシー をご覧ください。

3. 取得する情報

  • Google アカウントでの認証時に発行されるアクセストークン・リフレッシュトークン（運営者の YouTube チャンネルに動画をアップロードする権限 youtube.upload と、アップロードした動画のサムネイル設定・公開予約に使う権限 youtube）
  • アップロードした動画の ID と URL

視聴者・ほかのユーザーの情報、チャンネルの登録者情報、閲覧履歴などは取得しません。

4. 情報の使い方

取得した情報は、運営者が作った動画を運営者自身のチャンネルにアップロードし、タイトル・説明文・サムネイルを設定し、公開日時を予約するためだけに使います。広告・分析・第三者への提供には使いません。

5. 保存と共有

  • トークンは運営者のパソコンの中にだけ保存します。外部のサーバーには送りません（Google の API への送信を除く）。
  • アップロードした動画の ID と URL は、運営者が管理する Google スプレッドシートに記録します。
  • 取得した情報を第三者に販売・提供・共有することはありません。
  • 本アプリは Cookie を使いません。利用者の端末に情報を保存したり、端末から情報を読み取ったりもしません（上記のトークンの保存を除く）。

6. 削除と権限の取り消し

本アプリへのアクセス権は、いつでも Google アカウントのセキュリティ設定（サードパーティ アクセス） から取り消せます。取り消した場合、または利用をやめた場合、運営者は保存しているトークンを7日以内に削除します。API から取得した情報は、必要がなくなった時点、遅くとも30日以内に削除または更新します。

8. 変更

このポリシーを変更するときは、このページを更新し、制定日を書きかえます。

English

1. Scope

This policy applies to kirinuki-upload (the "App"), a private upload tool used by the owner (the "Owner") of the YouTube channel "ホロアソビ観察日誌【ホロライブ切り抜き】". The Owner is the App's only user.

2. Use of YouTube API Services

The App uses YouTube API Services. By using the App, users agree to be bound by the YouTube Terms of Service. For how Google handles information, see the Google Privacy Policy.

3. Information we access

  • OAuth access and refresh tokens issued when the Owner signs in with Google, granting permission to upload videos to the Owner's own channel (youtube.upload), and to set thumbnails and schedule publication of the uploaded videos (youtube).
  • The IDs and URLs of the videos the App uploads.

The App does not access data about viewers, other users, subscribers, or watch history.

4. How we use information

The information is used only to upload videos produced by the Owner to the Owner's own channel, set their title, description and thumbnail, and schedule their publication. It is not used for advertising or analytics and is not provided to third parties.

5. Storage and sharing

  • Tokens are stored only on the Owner's computer and are not sent to any server other than Google's APIs.
  • Uploaded video IDs and URLs are recorded in a Google Sheets spreadsheet managed by the Owner.
  • We do not sell, share, or disclose any information to third parties.
  • The App does not use cookies, and does not store or read information on users' devices (other than storing the tokens above).

6. Deletion and revoking access

Access can be revoked at any time via the Google security settings page (third-party access). When access is revoked or the App is no longer used, the Owner deletes the stored tokens within 7 days. Data obtained from the API is deleted or refreshed when no longer needed, and in any case within 30 days.
