kirinuki-upload

YouTube チャンネル「ホロアソビ観察日誌【ホロライブ切り抜き】」の運営者が使う、自分専用の投稿・管理ツール

このアプリについて

kirinuki-upload は、YouTube チャンネル「ホロアソビ観察日誌【ホロライブ切り抜き】」の運営者が、自分で編集した切り抜き動画を自分のチャンネルにアップロードし、公開日時を予約し、自分のチャンネルの成績を確かめるためのツールです。切り抜きは、元の配信者が公開している二次創作・切り抜きのガイドラインに沿って作っています。

  • 使うのはチャンネルの運営者1人だけです。ほかの人が登録・ログインして使うサービスではありません。
  • YouTube API サービス（YouTube Data API・YouTube Analytics API）を使って、次のことを行います。
    • 動画のアップロード（最初は非公開）、タイトル・説明文・タグ・サムネイルの設定、公開予約
    • 自分のチャンネルの動画の再生数・視聴時間・クリック率などの数字の確認
    • 自分の動画に付いたコメントのうち、字幕や名前のまちがいの指摘がないかの確認
    • 月に1回、YouTube の検索で、切り抜いている配信者の切り抜き動画がどれくらい出ているかを数える（数だけを記録します）
  • 公開する動画はすべて、運営者が公開前に内容を確認してから予約します。
  • ほかの人のチャンネルや動画を変更することはありません。

本アプリは YouTube API サービスを使っています。本アプリの利用には YouTube 利用規約 が適用されます。詳しくは 利用規約 と プライバシーポリシー をご覧ください。

About this app (English)

kirinuki-upload is a private tool used only by the owner of the YouTube channel "ホロアソビ観察日誌【ホロライブ切り抜き】" (Holo Asobi Observation Diary). Using YouTube API Services (YouTube Data API and YouTube Analytics API), it uploads clip videos edited by the owner to the owner's own channel, sets their title, description, tags and thumbnail, schedules their publication, and helps the owner review the channel's own performance. The clips follow the derivative-work and clipping guidelines published by the original creators.

  • The only user is the channel owner. It is not offered to the public and has no sign-up.
  • It reads analytics for the owner's own channel and checks comments on the owner's own videos for reports of mistakes (for example, wrong names in subtitles).
  • Once a month it counts, via YouTube search, how many clip videos of the clipped creators were published (only the counts are kept).
  • Every video is reviewed by the owner before it is scheduled for publication. It never modifies other users' channels or videos.

This app uses YouTube API Services; use of the app is subject to the YouTube Terms of Service. See the Terms of Use and the Privacy Policy.
