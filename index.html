kirinuki-upload

YouTube チャンネル「ホロアソビ観察日誌【ホロライブ切り抜き】」の運営者が使う、自分専用の投稿ツール

このアプリについて

kirinuki-upload は、YouTube チャンネル「ホロアソビ観察日誌【ホロライブ切り抜き】」の運営者が、自分で作った動画を自分のチャンネルにアップロードし、公開日時を予約するためのツールです。

  • 使うのはチャンネルの運営者1人だけです。ほかの人が登録・ログインして使うサービスではありません。
  • YouTube Data API を使って、動画のアップロード（最初は非公開）、タイトル・説明文・サムネイルの設定、公開予約を行います。
  • 公開する動画はすべて、運営者が公開前に内容を確認してから予約します。
  • ほかの人のチャンネルや動画、視聴者の情報を読み取ったり、変更したりはしません。

個人情報の取り扱いは プライバシーポリシー をご覧ください。

About this app (English)

kirinuki-upload is a private tool used only by the owner of the YouTube channel "ホロアソビ観察日誌【ホロライブ切り抜き】" (Holo Asobi Observation Diary). It uploads videos that the owner has produced to the owner's own channel, sets their title, description and thumbnail, and schedules their publication, using the YouTube Data API.

  • The only user is the channel owner. It is not offered to the public and has no sign-up.
  • Every video is reviewed by the owner before it is scheduled for publication.
  • It does not read or modify other users' channels, videos or viewer data.

See the Privacy Policy.
